Methods

MethodIdempotentTypical
GETYesRead
POSTNoCreate / action
PUTYesReplace whole resource
PATCHDependsPartial update
DELETEYesRemove
PUT vs PATCH PUT replaces the document. PATCH updates fields. PATCH is not always idempotent (increment a counter).

Status codes

CodeMeaning
200 / 201 / 204OK / created / no content
400 / 422Malformed vs semantic validation
401 / 403Not authenticated vs authenticated but forbidden
404 / 409 / 429Missing / conflict / rate limit
500 / 502 / 503 / 504Bug / bad gateway / unavailable / timeout
