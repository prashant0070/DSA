SQL and database internals

JOINs

flowchart LR
  U[users] --> Inner["INNER matching only"]
  U --> Left["LEFT all users + orders or NULL"]

Users with no orders: LEFT JOIN ... WHERE orders.id IS NULL.

WHERE vs HAVING WHERE filters rows before grouping. HAVING filters groups after GROUP BY.

Indexes

B-tree index Speeds equality and range. Composite indexes follow leftmost prefix. Function on a column can disable the index. EXPLAIN to see a full scan.

ACID and isolation

AtomicityAll or nothing
ConsistencyValid state
IsolationConcurrent transactions
DurabilityCommitted data survives crash

Phenomena: dirty read, non-repeatable read, phantom. Isolation: READ UNCOMMITTED → SERIALIZABLE.

flowchart TB
  T1[Tx A lock row 1] --> Wait
  T2[Tx B lock row 2] --> Wait
  Wait --> Deadlock["deadlock if A wants 2 and B wants 1"]
