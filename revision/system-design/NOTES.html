Building blocks

Stateless app No session in process memory — scale by adding instances behind a load balancer.
Cache Fast copy of hot data. Cache-aside is the default. Watch stampede and TTL.
Queue / stream Async work. At-least-once → idempotent consumers.
Shard Split data by key to scale writes. Hot keys need special handling.

CAP and consistency

Under partition you lean CP (refuse some ops) or AP (serve possibly stale). Say which feature needs strong consistency (payments, pass/fail) vs eventual (click counts).

Estimation habit

Method Monthly events → QPS. Peak ≈ 3–5× average. Storage = rows × bytes. Machines ≈ peak QPS / QPS-per-box. State assumptions.

Classic prompts

URL shortener, rate limiter, notifications, feed, chat, ride matching. SDET: see Automation design.
