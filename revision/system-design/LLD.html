FAANG LLD

Low-level design

35–45 minutes: use cases → types → interfaces → one sequence → threads → how you test it.

Clock

flowchart LR
  R["use cases"] --> T["types"]
  T --> I["interfaces"]
  I --> S["sequence"]
  S --> C["concurrency"]

Recipe

  1. Nouns → classes
  2. Verbs → methods
  3. Varying behavior → Strategy
  4. Construction → Factory
  5. Lookups → HashMap / Queue

Example — LRU

Invariant Map size ≤ capacity. Head = most recent. Tail = LRU. get/put O(1).
flowchart LR
  Map["HashMap key to node"] --> List["Doubly linked list"]
    
sequenceDiagram
  participant C as Client
  participant L as LruCache
  C->>L: put K V
  L->>L: move or insert at head
  alt over capacity
    L->>L: evict tail
  end

SDET LLD — parallel runner

sequenceDiagram
  participant W as Worker
  participant F as DriverFactory
  participant S as Session
  participant A as Artifacts
  W->>F: create config
  F-->>W: Session
  W->>S: run test
  alt failed
    W->>A: upload trace
  end
  W->>S: close

Invariant: session never shared across tests. Collector is thread-safe.
