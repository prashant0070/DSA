# Git for interviews and day-to-day engineering

**Notes:** [NOTES.md](NOTES.md)  
**Interview Q&A:** [INTERVIEW-QA.md](INTERVIEW-QA.md)

SDET interviews sometimes use Git as a practical engineering signal, especially at senior levels.

## Scope

- merge vs rebase
- cherry-pick
- revert
- reset concepts
- reflog
- bisect
- conflict resolution
- branching strategy

## Interview scenarios

- a production bug was introduced 5 commits ago; find it
- CI started failing after a refactor; isolate the change
- recover after a mistaken rebase or bad merge

## Why it matters

Lead-level quality engineering includes source-control fluency, incident recovery, and safe collaboration.
