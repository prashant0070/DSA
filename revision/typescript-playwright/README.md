# TypeScript for Playwright-heavy SDET roles

**Notes:** [NOTES.md](NOTES.md)  
**Interview Q&A:** [INTERVIEW-QA.md](INTERVIEW-QA.md)

Java remains the primary interview language in this repo. TypeScript exists here so you can be credible in modern Playwright teams.

## Scope

- variables and types
- interfaces and type aliases
- classes
- generics basics
- async / await and promises
- modules and imports
- arrays, maps, destructuring
- error handling
- npm and package.json basics
- Playwright config, fixtures, and projects

## Why this track exists

Many high-end SDET roles are Java for coding rounds but TypeScript in real automation code.

You should be able to:

- read Playwright code quickly
- write a test or fixture confidently
- understand async behavior
- discuss project config, auth setup, and reporters
