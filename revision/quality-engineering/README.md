# Quality engineering strategy

**Notes:** [NOTES.md](NOTES.md)  
**Interview Q&A:** [INTERVIEW-QA.md](INTERVIEW-QA.md)

Lead SDET is not just framework ownership. It is quality strategy at org level.

## Scope

### Test strategy

- test pyramid
- test trophy awareness
- testing quadrants
- shift-left and shift-right
- critical-path coverage
- risk-based testing

### Release quality

- release gates
- smoke vs regression vs exploratory
- acceptance criteria
- rollback and mitigation planning
- environment strategy

### Metrics

- escaped defects
- flaky rate
- MTTR
- regression duration
- release confidence
- defect detection efficiency
- critical-path automation coverage

### Organizational ownership

- what SDET owns vs what dev owns
- how to reduce E2E overuse
- when not to automate
- cost vs signal

## Interview questions

- What is your quality strategy for a product org?
- What metrics matter to leadership?
- How do you balance speed and confidence?
- How do you reduce a 6-hour regression without creating blind spots?
