# Level expectations — SDET II, SDET III, Lead SDET

Use this file to calibrate what different companies usually mean by each level.

## SDET II

### Technical bar

- solid easy/medium coding in one language
- framework usage plus moderate extension
- API/UI/mobile basics
- SQL, HTTP, and debugging fundamentals
- can explain one automation project end to end

### Behavioral bar

- ownership inside your scope
- teamwork and communication
- 4–6 decent STAR stories

### Typical rounds

- coding
- automation/framework discussion
- API/SQL/tooling
- behavioral

## Senior SDET

### Technical bar

- medium coding comfort
- framework architecture trade-offs
- CI/CD, debugging, SQL internals, some design
- can reduce flakiness and improve execution strategy

### Behavioral bar

- influence beyond own tasks
- metric-backed improvements
- 6–8 STAR stories

## SDET III

### Technical bar

- medium coding fluency plus selected advanced problems
- concurrency and Java engineering depth
- distributed systems basics
- test platform and system design ability
- observability, resilience, async testing awareness

### Behavioral bar

- multi-team ownership
- conflict handling and technical influence
- roadmap and architecture stories
- 8–10 strong STAR stories

## Lead SDET

### Technical bar

- credible coding and debugging
- defines quality strategy, not just scripts
- leads platform direction, metrics, and release quality
- designs test ecosystem and organizational quality model

### Behavioral bar

- org-wide influence
- mentoring and hiring
- executive communication
- measurable business impact
- hard trade-offs under constraints

## Cross-level differences

| Area | SDET II | SDET III | Lead SDET |
| --- | --- | --- | --- |
| Coding | solve | solve + design | design + review + guide |
| Framework | use well | architect well | platform strategy |
| Debugging | local failures | cross-service failures | org-wide failure patterns |
| Leadership | self | team/multi-team | org/platform |
| Metrics | mentions them | improves them | owns and reports them |
