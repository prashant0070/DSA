# Kubernetes for SDET interviews

**Notes:** [NOTES.md](NOTES.md)  
**Interview Q&A:** [INTERVIEW-QA.md](INTERVIEW-QA.md)

This track covers the K8s depth useful for CI runners, browser farms, test environments, and platform discussions.

## Scope

- pods, deployments, replica sets
- services and ingress
- config maps and secrets
- readiness and liveness probes
- jobs and cronjobs
- resource requests and limits
- scheduling basics
- HPA and autoscaling
- logs, rollouts, rollback
- namespaces and multi-tenant concerns

## Interview angle

- Playwright/Selenium worker scaling
- test environment isolation
- flaky infra due to bad probes or resource pressure
- running device/browser grids on K8s
