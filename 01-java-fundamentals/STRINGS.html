Immutability

In simple words A String is a locked notebook. “Changing” it means getting a new notebook.
String s = "hi";
System.out.println(s.toUpperCase()); // HI
System.out.println(s);               // hi
s = s.toUpperCase();
System.out.println(s);               // HI

Pool vs new

flowchart LR
  Lit["Literal hello"] --> Pool[String pool]
  New["new String"] --> Heap[Heap]
  Intern["intern"] --> Pool
    
String a = "hello";
String b = "hello";
String c = new String("hello");
System.out.println(a == b);      // true (typical)
System.out.println(a == c);      // false
System.out.println(a.equals(c)); // true — use this

StringBuilder (use in loops)

// Slow: s += i each time copies everything
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 5; i++) sb.append(i);
System.out.println(sb); // 01234

sb.reverse();
System.out.println(sb); // 43210

Everyday methods

String s = "banana";
s.charAt(1);           // 'a'
s.substring(1, 4);     // "ana"
s.indexOf("an");       // 1
s.contains("nan");     // true
"a.b".split("\\.");    // ["a","b"] — escape the dot!
"  hi  ".strip();      // "hi"
String.join("-", "a","b"); // "a-b"
