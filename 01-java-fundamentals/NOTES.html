1. Primitive vs reference

In simple words Primitive holds the number. Reference holds an address to an object.
int a = 10;
int b = a; b = 99;
// a is still 10

int[] x = {1, 2, 3};
int[] y = x; y[0] = 99;
// x[0] is 99 — same array
flowchart LR
  Var["int x = 5"] --> StackSlot["stack: 5"]
  Ref["String s"] --> Heap["heap: Ada"]

2. Autoboxing trap

Integer a = 100, b = 100;
System.out.println(a == b);      // often true (cache)
Integer c = 200, d = 200;
System.out.println(c == d);      // often false
System.out.println(c.equals(d)); // true — always use equals

4. Strings (summary)

String s = "hi";
s.toUpperCase();
System.out.println(s);          // hi — immutable
s = s.toUpperCase();            // HI

StringBuilder sb = new StringBuilder();
for (int i = 0; i < 5; i++) sb.append(i);
System.out.println(sb);         // 01234

5. Collections (summary)

List<String> names = new ArrayList<>();
names.add("Ada");
System.out.println(names.get(0)); // Ada

Map<String, Integer> freq = new HashMap<>();
freq.merge("to", 1, Integer::sum);
freq.merge("to", 1, Integer::sum);
System.out.println(freq.get("to")); // 2

Deque<Integer> stack = new ArrayDeque<>();
stack.push(1); stack.push(2);
System.out.println(stack.pop()); // 2

6. Exceptions

try {
  int age = Integer.parseInt("abc");

  System.out.println("not a number");
} finally {
  System.out.println("always runs");
}

7. Streams

List<Integer> out = List.of(1,2,3,4,5,6).stream()
  .filter(n -> n % 2 == 0)
  .map(n -> n * 10)
  .toList();
// [20, 40, 60]
