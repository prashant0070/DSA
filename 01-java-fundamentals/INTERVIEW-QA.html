A. Strings

A1 Why immutable? → security, thread-safety, pool, hash cache, Map keys.
A2 String vs Builder vs Buffer → immutable / mutable unsync / mutable sync.
A3 == vs equals → identity vs content; never == for text.
A4 Pool / intern → shared literals; intern() canonicalizes.
A5 += in loop → O(n²); use StringBuilder.
A6 substring modern Java → copies (7u6+).
A7 Anagram → freq array O(n) or sort.
A8 trim vs strip → ASCII-ish vs Unicode whitespace.

B–C. Arrays & lists

B2 Arrays.asList fixed size — no add.
C1 ArrayList vs LinkedList → prefer ArrayList; index O(1).
C2 ArrayList growth → ~1.5×, amortized O(1) append.
C3 Stack/queue → ArrayDeque (not legacy Stack).
C4 PriorityQueue → heap; iteration not sorted.

D. HashMap (high frequency)

D1 hash → bucket → list/tree; equals resolves collisions.
D2 Load factor default 0.75.
D3 equals + hashCode together for keys.
D4 HashMap allows one null key; ConcurrentHashMap allows none.
D5 HashMap not thread-safe.
D7 LinkedHashMap → order / LRU via removeEldestEntry.
D10 Fail-fast → CME on structural change during iteration.

E–J. Quick hits

E Comparable = natural; Comparator = external.
F Erasure; PECS (producer extends, consumer super).
H Integer cache −128..127; unbox null → NPE.
J No static WebDriver in parallel tests.
