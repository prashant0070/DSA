Two pointers

Opposite ends Sorted pair sum: if too small, left++; if too big, right--.
Same direction Write-index: MoveZeroes, unique prefix.
flowchart LR
  L["left"] --> Arr["sorted array"]
  Arr --> R["right"]

Sliding window

Fixed k Add nums[i], drop nums[i-k]. O(n).
Variable Expand right; shrink left while invalid. Each index enters/leaves once → O(n).
flowchart LR
  L2["left"] --> Win["window"]
  Win --> R2["right grows"]

Prefix sum

sum(i..j) = prefix[j+1] - prefix[i]. O(n) build, O(1) query. Subarray sum K: map of prefix counts.

Hashing

Complement (Two Sum), frequency, seen set. O(n) time, O(n) space average. Keys need equals/hashCode.

Binary search

Halve a sorted range. Also search on the answer: lo..hi on a value, can(x) monotonic. O(log n).

flowchart TB
  Range["lo ... hi"] --> Mid["mid"]
  Mid -->|too small| Lo["lo = mid+1"]
  Mid -->|too big| Hi["hi = mid-1"]

Graph / tree

BFS Queue, level order, shortest unweighted path. O(V+E).
DFS Recursion or stack. Components, tree height, islands. O(V+E) or O(cells).

Heap, intervals, DP, backtracking

Heap: top K, O(n log k). Intervals: sort by start, merge overlap. 1D DP: ways / pick-skip. 2D DP: grids. Backtracking: choose, recurse, undo.
